---

## 🎯 Objetivo

O **Cardápio Online** foi criado para substituir os cardápios impressos e facilitar a consulta pelos clientes, permitindo:  
- 📖 Visualização clara dos pratos.  
- 🖼️ Fotos, descrições e preços organizados.  
- 📱 Acesso rápido em qualquer dispositivo com navegador.  

---

## ✨ Funcionalidades

- ✅ Listagem de pratos com imagens, descrição e preço.  
- ✅ Layout responsivo e intuitivo.  
- ✅ Estrutura leve (HTML, CSS e JS puro).  
- ✅ Fácil de personalizar e atualizar.  

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** → Estrutura das páginas.  
- **CSS3** → Estilização e responsividade.  
- **JavaScript** → Funcionalidades e interatividade.  
- **Google Fonts & Ícones** → Melhor visual e legibilidade.  

---

## 📂 Estrutura do Projeto

Cardapio-online/

├── js/ → scripts JavaScript
